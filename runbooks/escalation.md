# Escalation

## Unknown cause escalation
If landing page, offer, tracking and traffic checks are all healthy but the drop is real, the affiliate manager reviews manually. Typical hidden causes: advertiser changed price or checkout, creative fatigue, seasonality, a competing promotion.

## Degraded checks
If a check could not run (tool unavailable), the triage result is not conclusive. Re-run triage when the system is back and do not close the incident on partial evidence.
