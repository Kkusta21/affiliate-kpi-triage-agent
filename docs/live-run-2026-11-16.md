## Problems that only the live runs found

1. The model rejected a hard-coded `temperature=0` with HTTP 400. Every planner step fell back
   to the policy. No sampling parameter is sent by default now.
2. The hypothesis prompt listed the allowed values without defining them, so the model named a
   cause on healthy evidence. The prompt now defines each value and says "do not guess".
